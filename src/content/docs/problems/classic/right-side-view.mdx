## 题目

给一棵二叉树，按层从浅到深（根在第 0 层），返回每一层最靠右的节点值。也就是站在树的右侧能看到的节点。

树的写法：

- Python：每个节点是一个三元组 `(值, 左子树, 右子树)`，空树是 `None`。写成三项的列表也可以。
- TypeScript：每个节点是一个三元素数组 `[值, 左子树, 右子树]`，空树是 `null`，类型是 `type Tree<T> = readonly [T, Tree<T>, Tree<T>] | null`。

例如“根 `A`，左孩子 `B`，右孩子 `C`，`B` 有一个左孩子 `D`”写成：

- Python：`("A", ("B", ("D", None, None), None), ("C", None, None))`
- TypeScript：`['A', ['B', ['D', null, null], null], ['C', null, null]]`

- 空树返回空列表。
- 节点值可以重复，也可以是任意类型，原样返回。
- 某个节点不是三项时，抛出 `ValueError`（TypeScript 里抛 `Error`）。

## 思路

一层一层地访问，每层从左往右排好，取最后一个。这叫按层遍历，也叫广度优先搜索（BFS），用一个先进先出的队列实现。

每弹出一个节点，先放左孩子、再放右孩子。第 k 层从左往右弹出，它们的孩子也就从左往右排进第 k + 1 层。

队列里相邻两层的节点是挨着的，要分清一层到哪结束。每层开始时，队列里恰好是这一层的全部节点，所以先记下队列长度 `width`，只弹 `width` 个。新放进去的孩子排在后面，留给下一轮。

用 T1 走一遍。深色是刚弹出的节点，浅色带边框的是当前层还没弹出的，更浅的是已入队的下一层，灰色是处理完的。

## 代码

两种语言的差异：

- Python 用 `collections.deque`，`popleft` 是 O(1)。JavaScript 数组的 `shift()` 要把后面的元素整体前移，是 O(n)，所以 TypeScript 版用“数组加头指针 `head`”模拟队列，弹出只是 `head++`。
- 每层的宽度在 TypeScript 里先存进 `const width`。如果直接写 `for (let i = 0; i < queue.length - head; i++)`，循环条件每次都会重新计算，刚放进去的孩子也会被算进这一层。Python 的 `range(len(queue))` 只在开头求一次值，没有这个问题。
- Python 解包 `value, left, right = ...` 遇到不是三项的节点会自己抛 `ValueError`。TypeScript 的数组解构不检查长度，少一项只会得到 `undefined`，所以显式检查了 `node.length !== 3`。

## 复杂度

n 是节点数，w 是最宽那一层的节点数，h 是树的层数。

- **时间 O(n)**：每个节点进队一次、出队一次。
- **空间 O(w)**：队列里最多同时有一层多一点的节点。另外答案列表有 h 项。

## 自测：两个方向写反的错误

<Aside type="caution" title="先在纸上算，再跑代码">
用 T1（`A` 的左孩子 `B`、右孩子 `C`，`B` 的左孩子 `D`），正确答案是 `[A, C, D]`。

如果你得到 `[A, C]`，是只沿着右孩子往下走，漏掉了左子树里更深的层。

如果你得到 `[A, B, D]`，你算出来的是左视图：要么放孩子时先放了右孩子，要么取的是每层第一个弹出的节点。两处只能改一处，同时改反就又对了。
</Aside>

## 延伸：额外空间只允许 O(树高)，怎么办？

按层遍历的队列要装下一整层。一棵 21 层的满二叉树，最后一层有 2²⁰ = 1048576 个节点，队列最多要同时放 1048576 个。可是这棵树只有 21 层。

换成深度优先搜索（DFS），并且**先访问右子树、再访问左子树**。这样每一层第一次被走到时，碰到的就是这一层最靠右的节点。当前深度正好等于答案列表的长度，就说明第一次走到这一层，这一层还没有答案。

在 T1 上：先到 `A`（深度 0，答案为空）记下 `A`；接着进右边的 `C`（深度 1，答案有 1 项）记下 `C`；`C` 没有孩子，回到 `B`，深度 1 已经有答案，跳过；再进 `D`（深度 2）记下 `D`。结果同样是 `[A, C, D]`。

递归写起来最短，但树退化成一条 10 万层的链时，Python 默认的递归深度上限是 1000，会直接报错。下面用显式的栈：栈是后进先出，所以先压左孩子、再压右孩子，右孩子就会先弹出来。

<Solution slug="right-side-view" file="followup" />

时间仍是 O(n)。栈里同时存在的，是从根到当前节点这条路上每层留下的至多一个左兄弟，所以额外空间是 O(h)。同一棵 21 层的满二叉树，栈最多只有 21 项。代价是：遇到一条很长的链，h 就等于 n，这时按层遍历的队列反而只有 1 项。两种做法该选哪个，取决于树是更宽还是更深。
