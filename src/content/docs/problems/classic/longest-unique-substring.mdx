## 题目

给一个字符串 `s`，返回其中最长的一段连续、且没有重复字符的子串的长度。

- 字符串可以含中文、空格和 emoji，一个 emoji 算一个字符。
- 空串返回 0。

## 样例

| 输入 | 输出 | 说明 |
|---|---|---|
| `"abba"` | `2` | `ab` 或 `ba`；`bba`、`abba` 都有重复 |
| `"查票查价"` | `3` | 最长的一段是 `票查价` |
| `""` | `0` | 空串 |

`"abba"` 用来抓一个常见错误：读到最后一个 `a` 时，左边界往回退。

## 思路

用一个窗口从左往右扫，再用一张表 `last` 记住每个字符上次出现的下标。读到重复字符时，左边界跳到上次位置的后一格，而且只往右跳，不往回退。扫一遍就够，O(n)。

暴力做法是枚举起点和终点，再检查有没有重复，要 O(n³)。

换个问法：如果这一段必须在下标 `right` 结束，它最早能从哪里开始？把这个起点叫 `left`，`s[left..right]` 就是以 `right` 结尾的最长合法片段。每个 `right` 都算一次长度，取最大值就是答案。`left` 和 `right` 都只往右走，这种做法叫滑动窗口。

`right` 右移一格、读进字符 `ch` 时，只有窗口里已经有 `ch` 才会出问题。查 `last[ch]` 就能判断：

- 表里没有 `ch`，或 `last[ch] < left`：上一个 `ch` 在窗口外，`left` 不动。
- `last[ch] >= left`：窗口里有旧的 `ch`，`left` 挪到 `last[ch] + 1`。

两条合成一句：`left = max(left, last[ch] + 1)`。`abba` 考的就是这个 `max`。

`left` 不会往左退。它表示“以当前 `right` 结尾时最早的合法起点”。`right` 多走一格，窗口只多一个字符，原来不合法的起点不会因此变合法，所以 `left` 只会不变或变大。从 2 退回 1，等于说 `bba` 合法，可它有两个 `b`。

`last[ch] = right` 要放在算完 `left` **之后**。先写表的话，查到的是刚写进去的 `right`，`left` 会跳到 `right + 1`，窗口变空。

## 复杂度

n 是字符串的字符数，u 是其中不同字符的个数。

- **时间 O(n)**：`right` 从头走到尾，每一步只做一次字典查询、一次写入和两次 `max`。`left` 虽然会跳，但跳跃是一步赋值，不是逐格移动。
- **空间 O(u)**：`last` 表里每种字符只占一项。全是小写英文字母时最多 26 项，含中文时上限就是字符串里出现过的字的种类数。

## 延伸：要返回子串本身呢？

题目改成返回最长的那一段，并列时取最靠左的一段。

`best` 改为同时记下起点 `start`，只在长度**严格变长**时更新，这样并列时保留的是先出现的那段。循环结束后切一次：`s[start : start + best]`。

不要每次破纪录都把当前子串复制一份。字符串长 n 时，破纪录最多 n 次，每次复制最长 O(n)，最坏会变成 O(n²)。只记两个整数、最后切一次，总复杂度仍是 O(n)。
