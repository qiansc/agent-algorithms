## 题目

写 `clipped_policy_loss(old, new, adv, eps)`，返回 n 个动作的 PPO 裁剪损失。

- `old[i]`、`new[i]` 是旧策略、当前策略选中第 i 个动作的概率。
- `adv[i]` 是第 i 个动作的优势。为正表示比平均好，为负表示更差。

对每一项计算：

- 比值 `r = new[i] / old[i]`；
- 把 r 限制到 `[1 − eps, 1 + eps]` 里，记作 `c`（小于下界取下界，大于上界取上界）；
- 这一项的目标值 `min(r · A, c · A)`。

返回 `−(各项目标值的平均)`。

三列须等长且非空，概率都在 (0, 1] 内，`0 < eps < 1`。不满足时抛 `ValueError`（TypeScript 抛 `Error`）。结果允许 1e-9 的误差。

## 样例

| `old` | `new` | `adv` | `eps` | 输出 |
|---|---|---|---|---|
| `[0.5, 0.5, 0.5]` | `[0.8, 0.2, 0.8]` | `[2, -1, -1]` | 0.2 | `0.0` |
| `[0.5, 0.5]` | `[0.55, 0.3]` | `[1, -2]` | 0.2 | `0.25` |

- 样例 1 第 3 项：先裁剪 r 再乘 A、省掉 `min`，坏动作的惩罚会被打折，结果变成 −0.1333。
- 样例 2：样例 1 的答案是 0，看不出符号。漏掉最后的负号，这里会得到 −0.25。

## 思路

逐项算 r、裁剪后的 c，取 `min(r·A, c·A)`，求平均再取负号。`min` 保证：往有利方向走最多加分到边界，往不利方向走的惩罚不打折。

### r 是什么

r 是新策略选这个动作的概率，相对采样那一刻的倍数。样例 1 第 1 项从 0.5 涨到 0.8，r = 1.6；第 2 项从 0.5 降到 0.2，r = 0.4。

只看 `r · A`，好动作（A > 0）的 r 越大目标越高，优化器会一直推高它的概率。但数据是旧策略采的，新策略离得越远，估出的好坏越不可靠。PPO 给 r 设了范围 [1 − ε, 1 + ε]，这里是 [0.8, 1.2]。超出范围后，再往同一方向走不再加分。

- 第 1 项，好动作，A = 2，r = 1.6。r · A = 3.2，c = 1.2，c · A = 2.4。取 2.4，加分最多算到 1.2 倍。
- 第 2 项，坏动作，A = −1，r = 0.4。r · A = −0.4，c = 0.8，c · A = −0.8。取 −0.8，已经压得够低，再压也不加分。
- 第 3 项，坏动作，A = −1，r 却涨到 1.6。r · A = −1.6，c · A = −1.2。取 −1.6，往错误方向走，惩罚不打折。

三项相加 2.4 − 0.8 − 1.6 = 0，损失为 0。浮点运算可能给出 7.4e-17 这样的数，在误差范围内。

`min` 每次取更悲观的那个，所以 PPO 的目标是不裁剪目标的一个下界。

实线变平的地方，梯度是 0。样例 1 第 1、2 项都在平的地方，这一批只有第 3 项推动参数，它会把那个坏动作的概率往回拉。

### 为什么最后取负号

`min(...)` 得到的目标越大越好。优化器默认做梯度下降，让数值越小越好，所以取负号当损失。要返回目标而不是损失时，就不要取负。

## 复杂度

n 是动作的个数。

- **时间 O(n)**：每一项做一次除法、一次裁剪、两次乘法和一次比较。
- **空间 O(1)**：只累加一个 `objective`，不需要额外数组。

## 延伸：坏动作的比值涨到 9 倍，惩罚要跟着涨到 9 倍吗？

给样例 1 再加一项：旧概率 0.1，新概率 0.9，A = −1。r = 9，这一项的目标是 min(−9, −1.2) = −9。四项合计 −9，损失 2.25，几乎全来自这一项。旧概率很小时 r 容易变得极大，一条样本就能主导整批的梯度。

一种改法叫 dual-clip：对 A < 0 的项，再加一个下限 `c · A`，c 是大于 1 的常数，常取 3。这一项的目标变成

`max( min(r·A, clip(r)·A), c·A )`

A ≥ 0 的项不受影响，`min` 已经让它们最多拿到 (1 + ε)·A。原解法只要在 `min` 之后，对负优势多做一次 `max`。

取 c = 3：新加的那一项变成 max(−9, −3) = −3。四项合计 2.4 − 0.8 − 1.6 − 3 = −3，损失 0.75。原来三项的 r 都不极端，结果不变。代价是 r 超过 c 后这一项梯度为 0，这条样本不再推动参数。
